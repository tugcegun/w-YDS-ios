wYDS — iPhone / iPad (App Store) uygulaması
==========================================

NE BU?
  Android uygulamasının iPhone/iPad eşi. wyds.com.tr'yi uygulama içinde açar ve telefonun
  kendi özelliklerini kullanır:
   - Google ile giriş (iPhone'un Google penceresi)
   - Apple ile giriş (App Store, Google girişi olan uygulamalarda bunu ŞART koşuyor)
   - Hatırlatma bildirimleri (Android'deki kuralların aynısı, sunucusuz)
   - Yedek dosyasını "Dosyalar"a kaydetme, PDF'yi Safari'de açma
   - Soldan kaydırınca geri, internet yokken "Tekrar dene" sayfası, açılışta kedi
  Paket kimliği: tr.com.wyds.app · Apple ID: 6836365741 · Sürüm 1.0.0
  Cihazlar: iPhone + iPad (iPhone Duo dahil). Ad her yerde bitişik: wYDS

NEDEN BİLGİSAYARDA DERLENMİYOR?
  iPhone uygulaması yalnız Mac'te (Xcode) derlenir. Mac olmadan bulutta derleyen
  Codemagic'i kullanıyoruz (ayda 500 dakika ücretsiz; bir derleme ~10 dk).
  Mac varsa: brew install xcodegen → xcodegen generate → WYDS.xcodeproj'u Xcode'da aç.

4) API ANAHTARI  (Codemagic'in yükleme yapabilmesi için)
   App Store Connect → Users and Access → Integrations → App Store Connect API
   → Team Keys → (+) Name: codemagic, Access: App Manager → Generate
   → .p8 dosyasını İNDİR (yalnız bir kez inebilir), "Issuer ID" ve "Key ID"yi not et.
   Bu dosya GİZLİDİR: GitHub'a koyma, sohbete yapıştırma.

6) CODEMAGIC
   https://codemagic.io → GitHub ile giriş → Add application → w-YDS-ios → iOS App
   → Teams → Integrations → App Store Connect → Connect:
      Name: wyds-asc  ·  Issuer ID, Key ID, .p8 dosyası (4. adımdan)
   → Teams → Code signing identities → iOS certificates → "Generate certificate"
      (Apple Distribution) → iOS provisioning profiles → "Fetch profiles"
      (tr.com.wyds.app, App Store).
   → Uygulamada codemagic.yaml'ı seç → Start new build.
   Derleme bitince yapı TestFlight'a kendiliğinden yüklenir.

8) TESTFLIGHT'TA DENE  (hem iPhone hem iPad'de)
   App Store Connect → TestFlight → Internal Testing → e-postanı ekle →
   cihaza "TestFlight" uygulamasını kur → wYDS'yi kur ve şunları dene:
   Google girişi, Apple girişi, bildirim izni, yedek kaydetme,
   internet kapalıyken açılış, iPad'de yatay/dikey çevirme.
